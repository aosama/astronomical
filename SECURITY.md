# Security Policy

## Supported Code

Security fixes target the current main branch. Astronomical has not published stable release branches yet.

## Reporting a Vulnerability

Use GitHub private vulnerability reporting from the repository Security page. Do not disclose a vulnerability, credential, private path, prompt, model inventory, or machine log in a public issue.

Include only the minimum reproduction details needed to understand impact. Redact user content and use fictional paths and credentials.

## Scope

Astronomical is a loopback-only, single-user local application. Reports involving an intentionally modified local binary, an already-compromised user account, or a non-loopback configuration rejected by Astronomical may be outside the supported threat model.
