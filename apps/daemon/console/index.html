    How this is measured

    Time saved is an estimate: decode retained hits multiplied by this machine's measured average decode storage-assignment read time. Prefill read seconds never enter it, and with no measured decode miss there is no speed to extrapolate from, so the estimate stays "not measured yet". Requested bytes are logical reads; the "Read from the SSD" figure is process-attributed physical disk input, which other worker reads can widen.
