# Experimental Aligned Expert Packs

This package preserves research into a tensor-major sparse-expert file layout and direct Metal input and output loading.

It is not part of Astronomical production serving, production configuration, public status, the macOS application, or default workspace builds. Astronomical production uses standard safetensors.

The package can prepare local research artifacts and exercise isolated data-plane qualifications. Those qualifications do not establish user-visible serving performance. Any proposal to return this capability to production requires a new representative end-to-end qualification and explicit approval.

The package intentionally publishes no benchmark result or performance claim.
