Storage / Expert paging

Are aligned expert packs worth another 34.23 GB?

Short answer: worth keeping as an optional Astronomical optimization, not worth universalizing until representative end-to-end measurements prove the gain.

IN THIS REPORT The problem What changes What is proven What is not Decision

01 / The problem

Standard model storage is optimized for distribution, not sparse paging.

A Qwen3.6 mixture-of-experts layer contains 256 experts but selects only eight for each token. Standard safetensors shards organize many model fields together. Fetching a routed subset therefore means calculating and issuing many small positional reads before the graphics processor can consume the selected weights.

Astronomical cannot assume all expert weights fit in memory. Under a lower user-selected memory ceiling, this storage path becomes part of token latency.

02 / What changes

One explicit preparation step creates tensor-major layer packs.

Each generated layer file groups expert weight, scale, and bias payloads into aligned contiguous regions. Adjacent selected experts become adjacent storage ranges. Astronomical can submit those ranges through Metal input/output directly into Machine Learning framework buffers.

The original model remains untouched. Preparation is explicit, resumable, revision-locked, byte-validated, and published only when every layer is complete.

03 / What is proven

The data path works without changing model math.

  • Qualified

    Prepared payload bytes match their source tensor segments before publication.

  • Qualified

    Selected ranges load into Machine Learning framework-owned Metal buffers and feed the unchanged gathered quantized matrix operation.

  • Qualified

    Missing, stale, or invalid packs fall back to bounded standard safetensors reads as one complete storage mode.

  • Qualified

    Adjacent expert selections reduce command count without reading unselected gaps.

Fewer commands are not a performance result. The user wins only if representative prompt processing or generation gets faster under the same memory ceiling.

04 / What is not proven

The current evidence does not justify a universal format.

One-layer data-plane measurements establish correctness and expose command behavior. They do not include all routing, memory admission, model computation, and request orchestration. Warm operating-system file pages can also hide physical storage behavior.

The missing result is a same-model A/B comparison using standard safetensors and aligned packs with the same approximately 1,000-token input, 1,000-token output, memory ceiling, precision, and cold/warm protocol.

05 / Decision

CURRENT VERDICT

Keep it optional. Measure it honestly. Do not export it yet.

The format is valuable infrastructure for Astronomical’s sparse paging path and cheap to ignore when absent. Integration with general runners would add maintenance before a material end-to-end gain is established.

SHARE THE VERDICT

Aligned expert packs turn scattered sparse-model fields into Metal-ready ranges. The path is correct; the end-to-end performance verdict is still open. That is why Astronomical keeps the format optional.
