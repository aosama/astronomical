# Getting started

## Installing

Astronomical needs a Mac with Apple silicon (an M-series chip) and a recent
macOS; the download page states the minimum.

1. Download it from https://getastronomical.com.
2. Open the disk image and drag Astronomical into Applications.
3. Open Astronomical. A chat window opens and an Astronomical item appears in
   the menu bar. The menu-bar item keeps models available after the chat
   window closes.
4. Follow the welcome: it suggests a model that suits this Mac and downloads
   it on the person's say-so.

You cannot do these steps for the person; walk them through.

## The terminal command

The `astronomical` command is not installed until the person asks for it,
with an option in the menu-bar item's menu. Afterwards
`astronomical --version` works. The command belongs to the app, so updating
the app updates it.

**Without the command** you can still help: Observatory does everything by
clicking, and programs and coding tools use the local address (see
`references/coding-tools.md`). The Mac App Store version has no terminal
command at all, so this is how to help its users.

## Observatory

Observatory is the app's control page, opened from the menu-bar item. It
shows memory, what is loaded and progress; it lists, downloads and removes
models; and it holds every setting. Send the person there for anything they
would rather click than type.

## Updating and removing

- The version downloaded from the website offers updates itself; the Mac App
  Store version updates through the App Store.
- Downloaded models are kept separately from the app and can be large. To get
  the disk space back, remove them in Observatory before removing the app.
